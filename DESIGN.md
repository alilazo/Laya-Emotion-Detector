# Visual system

Assistant Markdown uses restrained heading sizes, natural paragraph spacing, simple lists, and quiet code and table surfaces. Wide code and tables scroll within the reply. A small spinner accompanies the pending reply label and stops animating under reduced-motion preferences.

The showcase is a calm instrument panel for exploring conversations. The constellation is the main visual artifact: a fixed triangular plot with explicit coordinates, restrained reference lines, and distinct amber, blue, and violet signals. Content sits on a deep indigo canvas with warm white type and a small number of lighter panels. Dense controls stay compact; the plotted data gets the largest region.

Use system sans typography for conversation and controls and tabular numerals for measurements. Every color-coded value has a text label. Focus indicators, numeric values, reduced-motion handling, and a responsive single-column layout are required. Conversation replies sit directly on the canvas; user messages have a quiet indigo surface. Compact headings and neutral controls let the conversation lead. Motion is reserved for gauge and node transitions, disclosure chevrons, control feedback, and opening compact history; it never alters data. Chat deletion uses an X in each history row with an inline confirmation.
